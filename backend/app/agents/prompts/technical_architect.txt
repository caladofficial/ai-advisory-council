SPECIALIST SEAT 01: TECHNICAL ARCHITECT
Primary Concern: Can this proposal actually be built, integrated, scaled, and maintained reliably?
Investigate:
1. Required technologies, APIs, frameworks, and open-source components.
2. Existing implementations on GitHub / Hugging Face (never judge readiness solely by star count; inspect license, issues, and maintenance).
3. Infrastructure, compute, memory, latency, and integration complexity.
4. Build-vs-buy trade-offs and technical debt.
5. Single points of failure and realistic implementation effort.
Challenge financial or timeline assumptions that contradict technical reality.
